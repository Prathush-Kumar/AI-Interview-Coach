# 🤖 AI Interview Coach + Resume Analyzer

An AI-powered career assistant that analyzes resumes, compares them with job descriptions, identifies skill gaps, optimizes resumes for ATS, and generates personalized interview questions.

🔗 **Live Project:** https://ai-interview-coach.streamlit.app/

---

## 🚀 Overview

Finding the right job is not only about having a good resume. Your resume should match the job requirements, highlight the right skills, and prepare you for the interview.

**AI Interview Coach + Resume Analyzer** helps candidates prepare for job applications using Generative AI.

The application can:

- 📄 Analyze a resume uploaded as a PDF
- 🎯 Compare the resume with a job description
- 📊 Calculate a job-match score
- 🔍 Identify matching and missing skills
- 📚 Recommend skills to learn
- ✨ Suggest realistic resume improvements
- 🤖 Generate personalized interview questions
- 💡 Provide sample answers and key points
- 🎤 Support different interview types and difficulty levels

---

## ✨ Key Features

### 📄 1. AI Resume Analyzer

Upload your resume as a PDF and the system extracts and analyzes important information such as:

- Name
- Email
- Phone
- Summary
- Skills
- Education
- Projects
- Experience
- Certifications

---

### 🎯 2. Job Match Analyzer

Enter a job description and compare it with your resume.

The system provides:

- Job match score
- Matching skills
- Missing skills
- Skills to learn
- AI-generated explanation

This helps candidates understand how closely their resume matches a target role.

---

### ✨ 3. Resume Optimizer

The Resume Optimizer identifies realistic improvements that can make your resume stronger.

It provides:

- Current resume score
- Realistic potential score
- High-priority improvements
- Suggested resume text
- ATS keywords
- Skills to learn
- General improvement suggestions

The system does **not invent experience or skills** that are not present in the resume.

---

### 🎤 4. AI Interview Question Generator

Generate personalized interview questions based on:

- Resume
- Job description
- Interview type
- Difficulty level
- Number of questions

Supported interview types:

- Technical
- HR
- Behavioral
- Project Based
- Mixed

Each question includes:

- Sample answer
- Why the answer is good
- Key points to remember

---

## 🧠 Generative AI

The application uses OpenAI's API to perform:

```text
Resume
   ↓
PDF Text Extraction
   ↓
AI Resume Analysis
   ↓
Job Description
   ↓
Job Matching
   ↓
Resume Optimization
   ↓
Personalized Interview Preparation
```

The AI is used to analyze resume information, compare it with job requirements, identify skill gaps, optimize resume content, and generate personalized interview questions.
